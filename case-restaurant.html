Restaurant Menu Management System

Restaurant Menu Management System เป็นระบบหลังบ้านสำหรับร้านอาหารที่ใช้จัดการหมวดหมู่และเมนูอาหารบนหน้าแสดงผลของร้าน โดยออกแบบเพื่อช่วยให้พนักงานสามารถเพิ่ม แก้ไข จัดลำดับ และจัดการเมนูจำนวนมากได้อย่างรวดเร็วและเป็นระบบ โปรเจกต์นี้มุ่งเน้นการออกแบบ UX/UI สำหรับระบบที่มีข้อมูลจำนวนมาก พร้อมปรับปรุง workflow การทำงานให้ใช้งานง่าย ลดความซับซ้อน และช่วยให้เข้าถึงเมนูได้เร็วขึ้น

Research

จากการวิเคราะห์ลักษณะการใช้งานของระบบ พบว่าผู้ใช้งานหลักคือพนักงานและผู้ดูแลระบบ ซึ่งต้องจัดการเมนูจำนวนมากในแต่ละวัน กิจกรรมที่เกิดบ่อยคือการเพิ่มเมนูใหม่ แก้ไขข้อมูล และจัดลำดับการแสดงผล ปัญหาหลักคือเมนูมีหมวดหมู่จำนวนมาก ทำให้ต้อง scroll ยาว การค้นหาเมนูทำได้ยากเมื่อข้อมูลเพิ่มขึ้น การจัดลำดับเมนูและหมวดหมู่ใช้เวลานาน การสื่อสารระหว่างการจัดการข้อมูลยังไม่ต่อเนื่องพอ จึงเริ่มต้นออกแบบโดยโฟกัสที่การจัด Information Architecture และลดขั้นตอนในการทำงานของผู้ใช้งาน

Key Insight

ผู้ใช้งานไม่ได้ต้องการ “เพิ่มทุกอย่าง” พร้อมกัน แต่ต้องการเครื่องมือที่ต้องจัดการได้เร็วที่สุด การลดเวลาในการค้นหาและลดจำนวนการ scroll ส่งผลต่อประสิทธิภาพในการทำงานมากกว่าการเพิ่มฟีเจอร์จำนวนมากในหน้าเดียว

Problem

ระบบเดิมมีรายการหมวดหมู่และเมนูจำนวนมาก ทำให้ผู้ใช้งานต้อง scroll เป็นระยะทางยาวเพื่อค้นหาเมนูที่ต้องการจัดการ ส่งผลให้ workflow มีความซับซ้อนและใช้เวลานาน นอกจากนี้การจัดการเมนูหลายรูปแบบ เช่น การเปิด/ปิดการขาย การแก้ไขข้อมูล หรือการจัดลำดับ ยังต้องสลับหลายขั้นตอน ทำให้การใช้งานไม่ต่อเนื่อง

Solution

  • ลดการ scroll ด้วยระบบ Category Navigation
  • เพิ่ม Search เพื่อเข้าถึงเมนูได้เร็วขึ้น
  • รองรับทั้ง Grid View และ List View ตามลักษณะการใช้งาน
  • รวม Quick Actions ไว้ในหน้าเดียวเพื่อลดจำนวนขั้นตอน
  • ใช้ Drawer ในการเพิ่มและแก้ไขเมนู เพื่อให้ workflow ต่อเนื่องมากขึ้น

Key Features

  • ออกแบบ Sidebar และ Tab Navigation เพื่อช่วยจัดกลุ่มข้อมูลและลดการ scroll
  • รองรับการแสดงผลทั้งแบบ Grid สำหรับดูภาพเมนู และ List View สำหรับจัดการข้อมูลจำนวนมาก
  • ผู้ใช้สามารถแก้ไขเมนู ลบเมนู เปิด/ปิดการขาย จัดลำดับรายการได้จากหน้าเดียว

User Flow Diagram

Result

หลังจากปรับโครงสร้างและออกแบบ UX ใหม่ ระบบสามารถจัดการข้อมูลจำนวนมากได้เป็นระเบียบมากขึ้น ผู้ใช้งานสามารถเข้าถึงเมนูและหมวดหมู่ได้เร็วขึ้น รวมถึงลดขั้นตอนในการจัดการเมนูในแต่ละวัน การเพิ่ม Search, Category Navigation และ Flexible View ช่วยให้ระบบรองรับการใช้งานจริงในร้านอาหารที่มีเมนูจำนวนมากได้ดีขึ้น

Reflection

  • เรียนรู้การออกแบบระบบหลังบ้านที่มีข้อมูลจำนวนมาก และเข้าใจความสำคัญของ workflow สำหรับผู้ใช้งานจริงมากขึ้น
  • ความท้าทายหลักคือการจัดการข้อมูลจำนวนมากโดยยังคงทำให้ interface ใช้งานง่ายและไม่ซับซ้อนเกินไป
  • โปรเจกต์นี้ช่วยพัฒนาทักษะด้าน Information Architecture, Dashboard UX และ System Thinking ในการออกแบบผลิตภัณฑ์ที่เน้นประสิทธิภาพในการใช้งานจริง
