Self Check-in Kiosk Experience

โปรเจกต์นี้เป็นการออกแบบ UI สำหรับ Self Check-in Kiosk เพื่อใช้ในพื้นที่องค์กร สำหรับผู้มาติดต่อ ให้สามารถลงทะเบียนด้วยตนเองได้อย่างรวดเร็ว โดยไม่ต้องพึ่งพาพนักงานต้อนรับ ผู้ใช้งานสามารถเสียบบัตรประชาชน / พาสปอร์ต ถ่ายภาพเพื่อยืนยันตัวตน รับรหัส Wi-Fi สำหรับใช้งานภายในพื้นที่ และรับข้อมูลปลายทาง เช่น อาคาร / ชั้น / จุดติดต่อ เป้าหมายหลักคือการลดขั้นตอน manual, ลดเวลารอคิว เพิ่มความเร็ว และช่วยนำทางผู้ใช้งานภายในพื้นที่ได้อย่างชัดเจน

Research

จากการศึกษา flow เดิมและพฤติกรรมผู้ใช้งานพบว่า ผู้ใช้งานจำนวนมากไม่รู้ว่าต้องไปติดต่อที่ไหนต่อ หลังลงทะเบียน ต้องถามพนักงานซ้ำ เพิ่มภาระพนักงานเคาน์เตอร์ ขั้นตอนลงทะเบียนแบบเดิมใช้เวลานาน และเกิดคิวสะสม ผู้ใช้งานมีทั้ง first-time visitor และต่างชาติ นอกจากนี้ยังดู reference จากระบบ self check-in ในโรงพยาบาล / สนามบิน UI ของเครื่อง kiosk ที่มีการใช้งานจริง พบว่า UI ที่ดีจะมี step-by-step ชัดเจน ใช้ icon + visual ช่วยแทนข้อความ มี feedback ตลอดเวลา เช่น loading / success

Key Insight

ผู้ใช้งานต้องการความชัดเจนมากที่สุด ทุก interaction ต้องเข้าใจได้ทันทีโดยไม่ต้องคิด การมี feedback เช่น animation / loading / success screen ช่วยลดความกังวล ผู้ใช้มีเวลาจำกัด ระบบต้องเร็วและไม่ซับซ้อน

Problem

  • ขั้นตอนลงทะเบียนเดิมใช้เวลานานและมี human error
  • ต้องออกแบบ UI ให้ผู้ใช้งานสามารถลงทะเบียนได้ภายในเวลารวดเร็ว
  • เข้าใจขั้นตอนได้โดยไม่ต้องมีคนช่วยยืนยันตัวตนได้อย่างมั่นใจ
  • ผู้ใช้งานไม่รู้ว่าต้องไปไหนหลัง check-in ทำให้เกิดการถามซ้ำที่พนักงานหน้าเคาน์เตอร์

Solution

  • ออกแบบ UI ที่เน้น step-by-step flow ที่ชัดเจน
  • ใช้ visual + icon ช่วยอธิบายแทนข้อความ
  • รองรับ 2 ภาษา (TH / EN)
  • ใช้ animation และ feedback เพื่อให้ user มั่นใจในแต่ละขั้นตอน
  • หลังลงทะเบียนเสร็จ ระบบจะแสดงหน้าจอสรุป ระบุข้อมูลปลายทางอย่างชัดเจน เช่น อาคาร ชั้น จุดติดต่อ แผนก

User Flow Diagram

Key Features

  • Smart ID / Passport Scan อ่านข้อมูลอัตโนมัติ ลดการกรอกเอง
  • Face Capture for Verification ยืนยันตัวตน
  • Step-by-step Flow ชัดเจน
  • Wi-Fi Access Generation รับรหัสใช้งานทันที
  • Destination Guidance Screen แสดงข้อมูลปลายทางหลัง check-in เช่น อาคาร A ชั้น 5 ห้องประชุม 502

Result

  • ลดภาระหน้าที่พนักงานหน้าเคาน์เตอร์
  • ผู้ใช้งานสามารถไปยังจุดหมายได้ทันทีหลัง check-in
  • ประสบการณ์ใช้งานครบ end-to-end มากขึ้น
  • เพิ่ม perception ว่าองค์กรมีระบบที่เป็นมืออาชีพและทันสมัย

Reflection

โปรเจกต์นี้ทำให้เข้าใจว่าการออกแบบสำหรับ kiosk ต่างจาก mobile/web เพราะ user ไม่คุ้นเคย UX ที่ดีไม่ใช่แค่สวย แต่ต้องลดความลังเลของผู้ใช้ให้ได้มากที่สุด การสื่อสารผ่าน UI ต้องชัดทันทีโดยไม่ต้องคิด
