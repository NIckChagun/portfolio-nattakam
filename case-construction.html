Construction Management System

โปรเจกต์นี้เป็นประสบการณ์ในการออกแบบระบบบริหารโครงการก่อสร้าง โดยมีเป้าหมายเพื่อช่วยให้ทีมสามารถวางแผน จัดการ และติดตามความคืบหน้าของงานได้อย่างมีประสิทธิภาพมากขึ้น ระบบถูกออกแบบให้รองรับการทำงานของหลายบทบาท เช่น Project Manager, Technician และ Quality Control (QC) โดยเน้นการทำงานแบบ real-time และการสื่อสารภายในทีม

Research

จากการทำความเข้าใจ workflow ของงานก่อสร้างและลักษณะการทำงานของผู้ใช้ พบว่าผู้ใช้งานต้องทำงานในหน้างานที่มีข้อจำกัด เช่น เวลาและสภาพแวดล้อม ทำให้ต้องการระบบที่ใช้งานง่ายและรวดเร็ว การอัปเดตความคืบหน้าเป็น action ที่เกิดบ่อยที่สุด และมักหลงว่าเป็นขั้นตอนที่ใช้เวลา ผู้ใช้ต้องการเห็นเฉพาะข้อมูลที่จำเป็นในแต่ละช่วงเวลา ไม่ต้องการข้อมูลที่เยอะเกินไป การสื่อสารมักเกิดขึ้นแยกจากตัวงาน ทำให้ข้อมูลขาดความต่อเนื่อง

Key Insight

ผู้ใช้ไม่ได้ต้องการฟีเจอร์ที่ซับซ้อน แต่ต้องการระบบที่ช่วยให้ทำงานได้เร็วขึ้น โดยไม่ต้องคิดเยอะ

Problem

  • ข้อมูลโครงการกระจัดกระจาย
  • ไม่สามารถติดตาม progress ได้แบบ real-time
  • การสื่อสารระหว่างทีมไม่มีศูนย์กลาง
  • การอัปเดตหน้างานทำได้ยากและใช้เวลานาน

Solution

  • จัดการ Task และแผนงานได้ในที่เดียว
  • อัปเดตความคืบหน้าได้แบบรวดเร็วผ่านมือถือ
  • กำหนดผู้รับผิดชอบงานอย่างชัดเจน
  • รองรับการสื่อสารและการติดตามสถานะงาน

Key Features

  • Task Management - จัดการและติดตามงานในระบบเดียว
  • Progress Update - อัปเดตความคืบหน้าได้รวดเร็ว พร้อมแนบรูป
  • Clear Assignment - กำหนดผู้รับผิดชอบในแต่ละงานอย่างชัดเจน
  • In-task Communication - สื่อสารภายใน context ของงาน
  • Real-time Status Tracking - มองเห็นสถานะงานได้ทันที

Result

  • ลดขั้นตอนในการอัปเดตงาน ทำให้ผู้ใช้งานสามารถบันทึก progress ได้รวดเร็วขึ้น
  • เพิ่มความชัดเจนของสถานะงานและความรับผิดชอบในทีม
  • ลดการสื่อสารซ้ำซ้อน เนื่องจากข้อมูลรวมอยู่ในระบบเดียว
  • ช่วยให้การติดตามโครงการและการตัดสินใจทำได้รวดเร็วขึ้น

Reflection

  • การออกแบบระบบที่มีหลาย role ต้องคิดในระดับ workflow และข้อมูล
  • การลดความซับซ้อนของ action ที่เกิดบ่อย เช่น การอัปเดตความคืบหน้า ส่งผลต่อประสบการณ์ผู้ใช้โดยตรง
  • การออกแบบสำหรับการใช้งานจริงในหน้างาน ทำให้ต้องให้ความสำคัญกับความเร็วและความชัดเจน
